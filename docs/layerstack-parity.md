# Layer stack parity checklist

Substance-3D-Painter-comparable layer workflow. Milestone M3.

## Layers

- [ ] Fill layers (colour, material reference, projection).
- [ ] Paint layers.
- [ ] Effect layers (filters, generators).
- [ ] Groups with their own blending.
- [ ] Layer instancing (M9).

## Masks

- [ ] Per-layer mask.
- [ ] Colour/grayscale fills in masks.
- [ ] Generators and smart masks.
- [ ] Geometry masks.

## Blending

- [ ] Standard blend modes (normal, multiply, screen, overlay, …).
- [ ] Per-channel blending.
- [ ] Opacity.
- [ ] Anchor points (M9).

## Operations

- [ ] Reorder, duplicate, group, delete.
- [ ] Flatten group / flatten copy.
- [ ] Convert layer/mask to another type.
- [ ] All operations undoable and command-driven.
